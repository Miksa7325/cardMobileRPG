# Акт 8 «Чумной некрополь»: новые враги

## Особенности акта

**Зараза:** в колоду каждого боя замешаны 3 Раны. Второй особенности нет.

Тема — чумной город мёртвых: болезнь забивает колоду Ранами, Яд и гниль (Уязвимость), а мертвецы встают снова. Хороши карты, которые сжигают Раны (у Чернокнижника), и урон по всем.
