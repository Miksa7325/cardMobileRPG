# Особенности классов

**Утверждено автором 2026-11-10** (этап 7, шаг 2). Здесь — что отличает каждый класс: свойство, ресурс, стартовая реликвия, стартовая колода и три темы, по которым будет собрана его новая колода из 54 карт. Числа — по `docs/balance.md`.

Пометка **(новое)** — то, чего сейчас в игре нет и что я предлагаю; остальное уже работает.

## Общий каркас колоды

У каждого класса 54 карты: 4 стартовых вида, 16 обычных, 14 необычных, 10 редких, 7 эпических, 3 легендарных.

| Правило | Значение |
| --- | --- |
| Стартовая колода | 10 карт: 4 базовые атаки, 4 базовые защиты, 1 карта починки, 1 карта ресурса класса |
| Темы | У класса 3 темы. 50 нестартовых карт: примерно по 14 на тему и 8 общих |
| Типы карт | Примерно 24 атаки, 22 навыка, 8 сил |
| Силы | Только с необычной редкости; в каждой теме 2 силы, одна из них — эпическая или легендарная |
| Легендарные | 3 штуки — по одной на тему; у каждой эффект-правило |
| Карты весом 0 | Только силы и карты со «Сжечь»; у класса не больше 6 таких карт (у Убийцы — 10) |
| Починка | Карта починки есть в стартовой колоде и ещё 3–4 в колоде |

## Маг — подготовка заклинаний

| | |
| --- | --- |
| HP | 60 |
| Свойство | Любое заклинание можно поставить на **подготовку**: оно готовится очередью 2 × вес клеток и срабатывает само, на 50% сильнее. Каждая пустая клетка основной шкалы ускоряет подготовку на 1. Оглушение срывает ближайшее подготовленное заклинание |
| Ресурс | **Прилив:** +1 в начале каждого такта; чародейские карты сильнее за каждый Прилив. **Потолок 6 (новое)** — тактов вдвое больше, чем было ходов, и без потолка Прилив растёт вдвое быстрее задуманного |
| Стартовая реликвия | Лунный колокольчик: в начале боя +2 Прилива (было +1; при цене Прилива 1,5 ОС и картах, растущих от него, ≈ 10 ОС) |
| Родные статусы | Горение, Замедление, Оглушение; Сокрушение молнией |
| Стиль | Мало здоровья и огромный урон: тяжёлые заклинания готовятся заранее, лёд и время отодвигают удары врагов |

Вопрос «длина шкалы Мага» из старого этапа 7 закрыт: шкала бесконечная, отдельной вместимости нет.

Темы колоды:

1. **Огонь** — урон и Горение, тяжёлые заклинания с «Финалом» (лучше всего с подготовки).
2. **Лёд и время** — Замедление, Оглушение, блок; контроль шкалы врагов.
3. **Чары** — карты, растущие от Прилива, молнии с Сокрушением, добор карт.

| HP | 88 |
| Свойство | Носит 4 зелья (остальные 3). Его зелья весят 0. Карты варки дают зелье на выбор из двух; выбор — на остановке в конце такта |
| Ресурс | **Реагенты:** +1 за сваренное зелье, +2 за выпитое. Копятся весь бой. **Потолок 10 (новое)** |

3. **Смеси** — кислота (Сокрушение), зажигательные (Горение) и едкие (Яд) склянки по всем врагам.

## Что меняется в движке

| Изменение | Зачем |
| --- | --- |
| Потолок ресурса: Ярость, Тьма, Реагенты — 10, Прилив — 6 | Чтобы карты «+N за ресурс» имели предел в длинных боях |
| Убийца: 3 карты весом 0 за такт — свойство класса | Реликвий остаётся 10 общих, классовых больше нет |
| Алхимик: одна карта варки за такт | Ограничивает скорость варки |
| Стартовые реликвии: 5, 4 и +2 вместо 6, 6 и +1 | Выравнивание по бюджету 10 ОС |
| Стартовые колоды: 4 вида карт вместо 5–6 | Решение автора |
